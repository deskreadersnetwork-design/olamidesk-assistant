# OLAMIDESK ASSISTANT

AI-powered Telegram customer support bot for **Olamidesk**.

Built with Python, `python-telegram-bot`, DeepSeek AI, and Railway PostgreSQL.
Deployed on Railway, sourced from GitHub.

---

## Features

- 👋 Welcome message + interactive menu on `/start`
- 🤖 Natural-language answers powered by DeepSeek
- 🧠 Per-user conversation memory (survives restarts)
- 💬 Human-support enquiry flow with reference codes
- 🛠️ Admin commands: `/admin`, `/stats`, `/broadcast`, `/reply`
- 🔐 Rate limiting, admin authorization, graceful shutdown
- 🗄️ Railway PostgreSQL for persistent storage
